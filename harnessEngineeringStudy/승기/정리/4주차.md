# AI 스터디 4주차 - 서브에이전트와 객체 지향 설계 원칙 정리

## 1. 이번 주 핵심

이번 주 내용은 한 줄로 요약하면  
**"복잡한 작업은 책임을 나눠서 처리하고, 코드도 책임 분리를 기준으로 설계해야 한다"**는 쪽에 가까웠다.

특히 Claude Code의 서브에이전트 구조와 객체 지향 설계 원칙이 연결된다는 점이 인상적이었다.

***

## 2. Subagent는 왜 필요한가?

자료를 보면 Subagent는 메인 세션과 분리된 작은 작업 공간으로 이해할 수 있었다.

즉 Parent Context가 전체 작업의 목표와 맥락을 관리하고, Subagent는 그 안에서 특정 작업만 맡아서 처리하는 구조다.

이 구조의 장점은 대략 이렇게 정리된다.

- 메인 세션에 모든 시행착오와 로그를 다 남기지 않아도 된다.
- 최종 결과만 요약해서 넘기기 때문에 컨텍스트 과부하를 줄일 수 있다.
- 독립된 공간에서 시도하기 때문에 메인 작업 공간을 덜 오염시킨다.
- 필요한 권한만 제한적으로 주는 방식으로 더 안전하게 실행할 수 있다.

결국 큰 작업을 한 세션에 다 몰아넣기보다, 역할을 나눠서 처리하는 쪽이 더 안정적이라는 흐름으로 이해됐다.

***

## 3. 좋은 설계는 책임 분리에서 시작된다

이번 주 자료에서는 코드 설계에서도 가장 중요한 기준으로 책임 분리가 나왔다.

하나의 거대한 함수나 클래스가 모든 걸 다 처리하는 구조보다는, 각 역할을 분리해서 관리하는 쪽이 유지보수에 훨씬 유리하다는 내용이었다.

특히 객체를 나눌 때도 역할이 다르다는 점을 구분해서 봐야 한다고 정리돼 있었다.

- Entity  
  - ID를 가지고 생명주기가 있는 객체.

- Value Object  
  - 식별자보다 값 자체가 중요한 불변 객체.

- DTO  
  - 레이어 사이에서 데이터를 옮기기 위한 전달용 객체.

결국 요구사항을 그냥 함수 하나로 몰아넣지 말고, 어떤 책임을 어떤 객체가 가져야 하는지 먼저 분리해야 한다는 내용으로 이해됐다.

***

## 4. SOLID 원칙은 어떻게 연결되는가

이번 주에는 객체 지향 설계 원칙인 SOLID도 같이 연결해서 설명됐다.

핵심만 짧게 정리하면 이렇다.

- SRP  
  - 하나의 클래스나 함수는 하나의 변경 이유만 가져야 한다.

- OCP  
  - 새로운 기능은 확장으로 대응하고, 기존 핵심 로직은 함부로 수정하지 않는 쪽이 좋다.

- LSP  
  - 하위 타입이 상위 타입을 대체해도 전체 동작이 깨지면 안 된다.

- ISP  
  - 필요 없는 메서드까지 강제로 의존하지 않도록 인터페이스를 잘게 나눠야 한다.

- DIP  
  - 구체적인 구현보다 추상화에 의존해야 변경에 유연해진다.

결국 SOLID는 어려운 이론이라기보다, 나중에 요구사항이 바뀌어도 덜 아프게 설계하는 기준이라고 보면 될 것 같았다.

***

## 5. 안전한 실행과 기록 관리

이번 주 자료에는 코드 설계뿐 아니라 실행 안전성과 기록 관리도 같이 나왔다.

먼저 설계 판단과 실행을 분리해서, 모호한 요구사항을 AI가 임의로 추측하며 실행하지 않도록 하는 게 중요하다고 정리돼 있었다.

또 Claude Code 내부에서는 권한 검증, 위험 행동 차단, 샌드박스 같은 다중 레이어 제어를 통해 안전장치를 둔다는 점도 같이 나왔다.

기록 방식도 흥미로웠는데, Transcript는 기존 기록을 덮어쓰지 않고 계속 뒤에 붙이는 append-only 구조를 사용한다고 정리돼 있었다. 이런 구조 덕분에 세션 복원, 복사, 되감기 같은 작업이 가능하다는 흐름으로 이해됐다.

***

## 6. 기억할 포인트

이번 주 내용을 정리하면 아래 정도로 묶을 수 있다.

1. 큰 작업은 메인 세션 하나에 몰기보다 Subagent로 나눠서 처리하는 쪽이 효율적이다.
2. 코드 설계도 결국 책임 분리가 가장 중요한 기준이다.
3. Entity, Value Object, DTO처럼 객체 역할을 구분해서 설계해야 구조가 명확해진다.
4. SOLID 원칙은 확장성과 유지보수성을 높이기 위한 기준으로 볼 수 있다.
5. 실행 안전성과 세션 기록 관리도 Claude Code 구조에서 중요한 축이다.
